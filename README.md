# ModCloth-NLP-Project
# Fashion Clothing Fit & Quality Analysis Using NLP

A Natural Language Processing (NLP) project that explores and preprocesses customer reviews from the ModCloth Clothing Fit Dataset to prepare fashion-related text for fit and quality analysis.

### Dataset
- **Name:** ModCloth Clothing Fit Dataset
- **Source:** [UCSD Dataset Collection](https://cseweb.ucsd.edu/~jmcauley/datasets.html)
- **Records:** 82,790
- **Main Features:** `review_text`, `fit`, `quality`

### Techniques Used
- Dataset exploration and statistical analysis
- Text tokenization using NLTK
- Regular Expressions (Regex) for text cleaning
- Lowercasing and whitespace normalization
- Stemming using PorterStemmer
- Comparison of original and cleaned text
